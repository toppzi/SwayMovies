# Wallpapers

Themes expect files in `~/Pictures/Wallpapers/`.

Copy your wallpaper images there (filenames in `MANIFEST.txt`). They are **gitignored** by default because many are large.

## Required files

| File | Theme |
|------|--------|
| `wallhaven_w89pvq.jpg` | terminator |
| `star_wars.jpg` | starwars |
| `tiefighter.jpg` | starwars-light |
| `eighties.jpg` | eighties |
| `turtles1.jpg` | tmnt |
| `mandalorian.jpg` | mandalorian |
| `backtothefuture.jpg` | bttf |
| `predator.jpg` | predator |
| `Mortalkombat.png` | mortalkombat |

Optional: put copies in `wallpapers/files/` before running `./install.sh` to auto-copy them home.
